- **핵심 범위:** 자동화 수준 6개, 차량 1대, 기능 1개, ODD 1개, 센서 4개, 모듈 7개, 시나리오 2개, 안전 기능 개념 2개, 미실행 시험 계획 1개, 문서 출처 6개

## 결과

입력 데이터와 RDFS 확장 그래프의 SHACL 검증이 모두 통과했고, 각 단계 결과 위반은 0건입니다. RDFS 확장으로 추가된 형식 정보는 79개입니다. 질문 11개의 SPARQL 문법을 파싱했습니다.

로컬 스튜디오 API에서 전체 카탈로그 26개, 탐색 응답(클래스 15·속성 92·인스턴스 39), 질문 템플릿 11개, 페이지 응답 200과 `autonomous-driving` 선택 항목을 확인했습니다.

질의 실행과 골든 답변 비교, 소비자 호환 사례 실행, 자동 테스트 및 브라우저 화면의 시각 검토는 수행하지 않았습니다. 예시 시험은 `planned`이고 결과는 `not_run`입니다. 실제 차량·시뮬레이터·도로 시험이나 안전 검증이 이루어진 것으로 해석하면 안 됩니다.

## 데이터 근거와 경계

SAE J3016, NHTSA 자동주행 안전·ODD 문서, Autoware 스택 및 차량 인터페이스, AWSIM 시뮬레이터 문서를 출처 개체로 연결했습니다. SAE 수준은 분류 용어로만 포함했으며 가상 셔틀 주행 기능에는 평가 수준을 할당하지 않았습니다. 캠퍼스 셔틀, 센서 구성, ODD, 모듈 연결, 도로 시나리오와 안전 기능은 합성 학습 자료입니다.
