# `domain` 온톨로지 등록 보고서

**결과:** 로컬 프로필 등록 및 스튜디오 읽기 확인 완료  
**상태:** 초안 `0.1.0`; 릴리스 URI 미정  
**기준일:** 2026-10-08

## 등록 내용

지식·업무·응용 분야를 분류하고, 로컬 온톨로지 프로필, 범위, 출처, 외부 매핑의 검토 상태를 연결하는 온톨로지를 등록했다. `domain`은 DNS 도메인 모델이 아니다.

| 항목 | 값 |
|---|---:|
| 클래스 | 11 |
| 속성 | 99 |
| 분류 개념 | 12 |
| 직접 계층 링크 | 8 |
| 예시 인스턴스 | 40 |
| 데이터 트리플 | 524 |
| competency questions | 12 |
| 로컬 프로필 배정 예시 | 5, 모두 `proposed` |
| 외부 매핑 예시 | 1, `not_started`, 외부 대상 URI 미설정 |

분류 체계는 예시 초안이다. 프로필 배정은 제안 상태이며, 외부 분류 체계와의 매핑 승인을 주장하지 않는다. 검토는 예정 상태이고 릴리스 네임스페이스는 정해지지 않았다.

## 확인한 항목

| 확인 | 결과 |
|---|---|
| Turtle/OWL 그래프 동등성 | 일치 |
| SHACL 원본 데이터 | 적합, 위반 0건 |
| SHACL 추론 데이터 | 적합, 위반 0건 |
| competency query 문법 | 12개 파싱 완료 |
| 질문 답변 계약 | 12개 ID/변수/행 구조 확인; 실제 결과 비교 안 함 |
| 소비자 호환 TriG | 56 quad 파싱; 사례 실행 안 함 |
| API 카탈로그 | 30개 프로필에 `domain` 포함 |
| 탐색기 API | 11 클래스, 99 속성, 40 인스턴스 |
| 질문 템플릿 API | `DOM-01`–`DOM-12` 12개 |
| 선택 메뉴 페이지 | HTTP 200, `domain` 옵션 확인 |

SPARQL 질의 실행, 답변 계약과의 대조, 소비자 예시 실행, 자동 테스트, 브라우저 시각 검수는 하지 않았다. 선택 메뉴 확인은 HTTP 응답 HTML에서 옵션을 읽은 결과다.

상세 모델과 범위는 [DOMAIN_ONTOLOGY.md](../DOMAIN_ONTOLOGY.md)에 기록했다. 기계 판독 가능한 지표와 파일 해시는 [domain-ontology.json](domain-ontology.json)에 보관한다.
