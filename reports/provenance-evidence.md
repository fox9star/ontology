# 출처 검증 집계

등록 미디어 3개의 근거 주장을 총 9개 작성했습니다. 등록 복사본 3개 모두
등록 SHA-256과 일치하고, 현재 로컬 원본 복사본 3개도 같은 바이트 지문을
갖습니다. 원본 생성 이력 3개와 원본 최초 출처 3개는 독립적인 근거가 없어
각각 미확인 상태로 기록했습니다.

| 확인 범위 | 직접 관찰 | 독립 확인 | 미확인 | 검사 실패 |
|---|---:|---:|---:|---:|
| 등록 파일 무결성 | 3 | 0 | 0 | 0 |
| 원본 생성 이력 | 0 | 0 | 3 | 0 |
| 원본 최초 출처 | 0 | 0 | 3 | 0 |

검사 시점과 기계 판독 결과는 provenance-evidence.json 및 별도의
provenance-evidence-check.json을 기준으로 확인합니다. 공유 집계에는
프로젝트·자산 식별자, 로컬 경로, 개인 경로, 지문을 포함하지 않습니다.

해시 일치는 로컬 바이트가 같다는 근거입니다. 등록 도구 버전은 원본 생성
모델의 근거로 사용하지 않았으며 생성 프롬프트와 최초 출처를 추정하지
않았습니다. 실제 출처 확인에는 별도의 독립 검토가 필요합니다.
