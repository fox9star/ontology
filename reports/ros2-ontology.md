# ROS 2 온톨로지 등록·검증 보고서

- **프로필:** `ros2` 0.1.0, 개발 초안
- **모델:** 클래스 13개, 속성 71개, 인스턴스 40개, 예시 그래프 370 트리플
- **초기 데이터:** 패키지 9, 노드 4, 토픽 2, 서비스 1, 액션 1, 메시지 형식 4, QoS 3, 하드웨어 3, 컨트롤러 1, 좌표 프레임 4, 문서 출처 7
- **탐색 질문:** 10개 (`ROS2-01`–`ROS2-10`)

## 결과

기본 입력 그래프와 RDFS 확장 그래프의 SHACL 검증이 모두 통과했습니다. 각 단계 위반은 0건이며, 확장 과정에서 추가된 형식 정보는 80개입니다. 질문 10개의 SPARQL 문법도 파싱했습니다. 질문 결과 실행·정답 비교와 호환성 사례 실행은 하지 않았습니다.

로컬 스튜디오 API에서 프로필을 읽고 탐색 응답(클래스 13, 속성 71, 인스턴스 40), 질문 템플릿 10개, 페이지 응답 200 및 `ros2` 선택 항목을 확인했습니다. 카탈로그 전체는 25개 프로필을 반환했습니다. 브라우저 화면의 시각적 검토와 자동 테스트는 하지 않았습니다.

스튜디오 탐색 API를 확인하는 동안 기존 `ontology_modules.json`에서 JSON 구문 오류와 중복된 `politics-schema.ttl` 항목을 발견했습니다. 구분 쉼표를 복구하고 중복 항목 하나를 제거해 로컬 스키마 모듈 로딩을 정상화했습니다. ROS 2 프로필은 카탈로그 자동 검색으로 등록되므로 별도 고정 목록 항목은 추가하지 않았습니다.

## 데이터 범위

공식 ROS 문서는 토픽·서비스·액션, QoS, `tf2`, `ros2_control`, 표준 `Temperature` 메시지와 `SetBool` 서비스 근거로 연결했습니다. 가상 온실의 사용자 정의 토양 수분 메시지와 관수 액션, 노드 연결, 하드웨어 배선 및 컨트롤러 구현은 합성 학습 예시입니다. 실제 시스템 배포나 안전 동작 검증을 나타내지 않습니다.

상세 개념과 출처 링크는 [ROS2_ONTOLOGY.md](../ROS2_ONTOLOGY.md)에 있습니다. 기계 판독용 검증 수치와 프로필 산출물 SHA-256은 [ros2-ontology.json](ros2-ontology.json)에 기록했습니다.
