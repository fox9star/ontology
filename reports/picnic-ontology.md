# 소풍 온톨로지 등록 기록

2026-10-05, 프로파일 `picnic`, 버전 `0.1.0`, 초안 상태입니다. [설명서](../PICNIC_ONTOLOGY.md), [기계 판독 기록과 파일 해시](picnic-ontology.json).

| 항목 | 결과 |
| --- | --- |
| 클래스 / 속성 | 8 / 39 |

모든 예제는 가상 자료이며 계획에 `recordKind "synthetic"`을 표시했습니다. 두 계획 모두 초안 상태로, 실제 장소·가격·예약·예보를 조회하거나 생성하지 않았습니다. 날씨 정보는 미확인 상태로 유지하고 확인 시각·출처를 넣지 않았습니다.

취소된 비용을 제외한 가상 배정 합계는 정원 계획 32,000원, 공원 계획 34,000원입니다. 각각 예산 30,000원과 60,000원에 대비해 예산 초과와 잔여 예산의 예제를 제공합니다. 준비물의 부족 수량, 누락된 담당자, 미확인 날씨도 별도 조회 항목으로 구성했습니다.

검증 규칙은 일정의 시작·종료와 계획 범위, 활동 순서의 중복, 양수 필요 수량·음수가 아닌 포장 수량, 같은 계획의 참가자·준비물 배정, 날씨 대상 날짜, 준비 완료 상태의 조건을 다룹니다. `ready`는 입력 기록이 갖춰졌다는 의미입니다.

완성된 파일은 준비 디렉터리에서 이름 변경으로 공개했습니다. 기존 프로파일·데이터를 덮어쓰지 않았으며 앱·레지스트리·검색 화면의 자동 발견 기능을 사용합니다. README에 설명서 링크를 추가했습니다.

자동 테스트, 질문의 고정 정답 대조, 브라우저 시각적 렌더링 확인은 이번 작업에서 실행하지 않았습니다. 위 결과는 초기 RDF의 입력 검증과 실행 중 앱의 조회 응답에 한정합니다. 공개 릴리스 URI는 미정이며 개발용 `example.org` namespace를 사용합니다.
